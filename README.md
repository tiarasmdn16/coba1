# 🌍 PRGG 2025 – WebGIS Teknik Geodesi UGM

Website ini merupakan **Landing Page & WebGIS PRGG 2025** yang dikembangkan oleh  
Program Studi **Teknik Geodesi – Universitas Gadjah Mada**.

Website dibuat menggunakan **HTML, CSS, JavaScript**, dan **peta interaktif dari QGIS2Web (Leaflet)**  
serta dipublikasikan melalui **GitHub Pages**.
